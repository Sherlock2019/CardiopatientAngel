# First week

**Day 1:** access (GitHub, CI, Knowledge Hub — no production access), `docker compose up`, log in as each demo role.
**Day 2:** architecture tour: SYSTEM_ARCHITECTURE.md, ADR-001..007, the lifecycle page.
**Day 3:** run `pytest`, `npm test`, Playwright; read KB-0001 and KB-0002.
**Day 4–5:** pick a "good first issue", open a PR with the template, get two reviews, see it through CI.
